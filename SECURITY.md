# Security

This is a self-hosted, single-owner MVP. Review
[the security and privacy guide](docs/security.md) before exposing it publicly.
Only the latest source release is currently supported; there is no maintenance
commitment for older snapshots.

## Reporting a vulnerability

Use this repository's **Security → Advisories → Report a vulnerability** option
for a private report. If that option is unavailable, open an issue asking for a
private reporting channel without posting exploit details or sensitive data.
Do not post provider keys, bearer tokens, OAuth data, pairing codes, public
deployment addresses, real phone numbers, or unredacted call records.

Describe affected versions, the trust boundary involved, a minimal reproduction
with fictional data, and the impact. Do not test against the author's or any
other person's deployment without authorization.
